## Motion vocabulary

- Drawer grows from the home search portal; avoid a hard page switch.
- Search keeps drawer context and brings the query field into focus.
- App icons remain system-provided and launch actual package activities.
- Wallpaper stays visible beneath restrained translucent surfaces.
