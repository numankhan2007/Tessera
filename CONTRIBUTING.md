# Contributing to Tessera

1. Keep launcher behaviour native and system-backed.
2. Do not add simulated Android app windows in place of real app launching.
3. Preserve wallpaper visibility; avoid opaque full-screen panels unless interaction requires them.
4. Keep motion interruptible and respect reduced-motion and system animation settings.
5. Test install/update/uninstall, navigation modes, system insets, font scaling and app launching on a physical device.
6. Never commit signing keys, local SDK paths, private API keys or keystores.
